# A profile you can hear

## Purpose

Demonstrate personality before conversation.

## Audience

People who find photo-first profiles emotionally flat.

## Story

A fast profile grid stops when one funny voice answer changes the viewer’s expression.

## 15-second script

**0.0–2.0s** Profiles move past quickly.

**2.0–7.0s** One voice answer plays.

**7.0–12.0s** A genuine smile and meaningful reply.

**12.0–15.0s** *More than a photo. Start with something real.*
